# 容大 RP328 网络打印机排障流程

## 步骤汇总

1. **打印机连上路由器**
   - 使用网线连接路由器。
   - 打印机自动 feed 出测试页，查看其中的 IP 地址。

2. **确认是否能正常打印**
   - 如果打印测试页成功输出，则无需进一步操作。

3. **检查网络连通性**
   - 在 Windows 电脑上运行 `ipconfig`，查看当前 WiFi 的 IP 地址。
   - 确认电脑和打印机是否在同一网段。
   - 使用 `ping [打印机IP]` 测试连通性。

4. **临时修改电脑 IP**
   - 打开无线网适配器的 IPv4 设置。
   - 将电脑 IP 改为与打印机同网段的地址。

5. **访问打印机配置页面**
   - 在浏览器中输入打印机 IP。
   - 修改打印机 IP，使其与电脑处于同一网段。

6. **恢复电脑网络设置**
   - 将无线网适配器 IPv4 设置改回自动获取（DHCP）。

7. **安装/重装驱动**
   - 下载并安装容大 RP328 专用驱动。
   - 在 Windows 打印机属性中选择正确的驱动。
   - 再次打印测试页，确认正常输出。
